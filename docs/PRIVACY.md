# Ιδιωτικότητα · dwrean Profit

**Τελευταία ενημέρωση: 09/11/2026**

Το dwrean Profit σχεδιάστηκε με βασική αρχή ότι **τα οικονομικά στοιχεία σου δεν χρειάζεται να φύγουν από τη συσκευή σου** για να γίνουν οι υπολογισμοί.

## Πώς λειτουργεί

Η εφαρμογή είναι ένα στατικό site HTML, CSS και JavaScript χωρίς backend ή λογαριασμούς χρηστών. Οι πράξεις εκτελούνται τοπικά στον browser σου. Ο κώδικας της εφαρμογής δεν στέλνει τον τζίρο, τα έξοδα ή άλλες τιμές που συμπληρώνεις σε κάποιο server.

Για να μη χρειάζεται να τα ξαναγράφεις, οι τιμές αποθηκεύονται στο **localStorage** του browser στη συγκεκριμένη συσκευή και στο συγκεκριμένο προφίλ. Δεν είναι συγχρονισμένες ανάμεσα σε υπολογιστές.

## Εξαγωγή δεδομένων

Όταν επιλέγεις εξαγωγή PDF, CSV ή JSON, δημιουργείται αρχείο στη συσκευή σου. Το αρχείο μπορεί να περιέχει οικονομικά στοιχεία· διαχειρίσου το όπως κάθε ιδιωτικό έγγραφο.

Η εισαγωγή αρχείου JSON γίνεται τοπικά. Μην εισάγεις αρχεία από άγνωστες πηγές.

## Κοινόχρηστες συσκευές

Οποιοσδήποτε έχει πρόσβαση στο ίδιο προφίλ browser ενδέχεται να δει τα αποθηκευμένα στοιχεία. Χρησιμοποίησε την επιλογή **Επαναφορά** για να αντικαταστήσεις τις συμπληρωμένες τιμές με τα αρχικά παραδείγματα ή εκκαθάρισε τα δεδομένα του site από τις ρυθμίσεις του browser.

## Φιλοξενία και εξωτερικοί σύνδεσμοι

Η εφαρμογή μπορεί να φιλοξενείται στο **GitHub Pages**. Η υπηρεσία φιλοξενίας ενδέχεται να καταγράφει συνήθη τεχνικά δεδομένα πρόσβασης σύμφωνα με τους δικούς της όρους. Ο κώδικας του dwrean Profit δεν ενσωματώνει υπηρεσία analytics ή διαφημιστικού tracking.

Οι σύνδεσμοι προς ΑΑΔΕ, e-ΕΦΚΑ, Υπουργείο Οικονομικών και dwrean.net ανοίγουν εξωτερικά sites, με τις δικές τους πολιτικές απορρήτου.

## Επικοινωνία

Για θέματα ή προτάσεις μπορείς να ανοίξεις ένα [GitHub Issue](https://github.com/dwrean-net/dwrean-Profit/issues). **Μη δημοσιεύεις** ΑΦΜ, στοιχεία πελατών, αποδείξεις ή πραγματικά προσωπικά οικονομικά δεδομένα σε δημόσια Issues.
